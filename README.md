# مُفتِّش النص العربي — Arabic Text Integrity Inspector

أداة ويب مجانية تعمل بالكامل داخل المتصفح لفحص ملفات Word (`.docx`) العربية بحثاً عن:

- **العلامات الخفية غير المرئية** التي غالباً ما تخلفها نماذج الذكاء الاصطناعي وأدوات المعالجة الآلية:
  - مسافة صفرية العرض `ZWSP` (U+200B)، الفاصل الصفري `ZWNJ` (U+200C)، الواصل الصفري `ZWJ` (U+200D)
  - علامات الاتجاه `LRM/RLM/ALM` (U+200E، U+200F، U+061C) وعلامات العزل والتضمين (U+2066–U+2069، U+202A–U+202E)
  - الرموز الرياضية الخفية (U+2061–U+2064)، `BOM` (U+FEFF)، الشرطة الاختيارية (U+00AD)، وغيرها — **23 رمزاً**
- **كل الحركات العربية (التشكيل)**: الفتحة والضمة والكسرة والتنوينات والشدة والسكون والألف الخنجرية (U+064B–U+0652، U+0670)، إضافة إلى الحركات الموسّعة والعلامات القرآنية (U+0615–U+061A، U+0653–U+065F، U+06D6–U+06ED، U+08D3–U+08FF)

تعرض الأداة **مؤشر سلامة من 100** مع بيان عوامل الخصم، ومواضع كل علامة مع سياقها، ومعاينة مميَّزة للنص،
وتتيح تنزيل **تقرير HTML** أو **نسخة Word منقّاة** أُزيلت منها العلامات مع الحفاظ على التنسيق.

> **تنبيه:** النتيجة استدلالية (Heuristic) وليست دليلاً قاطعاً. وجود الحركات طبيعي في المصاحف والشعر وكتب تعليم القراءة،
> لذا تُقدَّم الكثافة والسياق بدل الحكم المطلق — والعلامات الخفية هي المؤشر الأقوى.

## التشغيل على GitHub Pages

الأداة **ملفات ثابتة بالكامل** (HTML + CSS + JS) ولا تحتاج أي خادم أو إعداد:

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `arabic-ai-checker`).
2. ارفع هذه الملفات إلى الجذر: `index.html` و `style.css` و `chars.js` و `engine.js` و `app.js`
   (ومجلد `sample/` اختياري — يحوي ملفات تجريبية).
3. من إعدادات المستودع: **Settings ← Pages ← Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / المجلد: **/ (root)** ← ثم **Save**.
4. بعد دقيقة تقريباً تصبح الأداة متاحة على:
   `https://<username>.github.io/<repo-name>/`

### بدائل أخرى
- أي استضافة ثابتة: Netlify و Cloudflare Pages و Vercel — اسحب المجلد وأفلتها وستعمل مباشرة.
- أو افتح `index.html` محلياً في المتصفح مباشرة (يحتاج اتصالاً بالإنترنت عند أول فتح لتحميل خط Cairo ومكتبة JSZip من CDN).

## كيف تعمل؟

ملف `.docx` هو أرشيف ZIP يحوي ملفات XML. تقوم الأداة بـ:

1. فك الضغط داخل المتصفح عبر [JSZip](https://stuk.github.io/jszip/) وقراءة:
   `word/document.xml` (النص الرئيسي) + الترويسات `header*.xml` + التذييلات `footer*.xml`
   + الحواشي `footnotes/endnotes` + التعليقات `comments`.
2. مسح كل حرف من كل فقرة على قاعدة بيانات العلامات (`chars.js`).
3. حساب المؤشر: الخصم الأكبر للعلامات الخفية (أقوى مؤشر آلي)، ثم لكثافة الحركات
   ونسبة الكلمات المُشكَّلة بالكامل (نمط شائع في النصوص المولّدة آلياً).
4. التنظيف (اختياري): إعادة بناء أرشيف docx بعد حذف العلامات الخفية — واختيارياً الحركات أيضاً — من نص XML مع الحفاظ على كل تنسيقات Word.

**الخصوصية:** لا يُرفع أي ملف ولا تُجمع أي بيانات — كل الفحص يجري في متصفحك، ويمكنك حتى قطع الإنترنت بعد فتح الصفحة (وضع اللصق يعمل دون اتصال).

## بنية الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة (عربية RTL) |
| `style.css` | التنسيق والتصميم |
| `chars.js` | قاعدة بيانات العلامات الخفية والحركات + منطق التحليل والمؤشر |
| `engine.js` | محرك docx: الاستخراج، التنظيف، التقرير، الاختبار الذاتي |
| `app.js` | التحكم بالواجهة والعرض والتنزيلات |
| `sample/` | ملفات Word تجريبية (موثَّبة بعلامات خفية + نسخة نظيفة) |
